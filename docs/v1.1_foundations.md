## 1. Reconnaissance (novelty boundary, 2026-11-09)

| System | What it does | Relevant difference |
|---|---|---|
| SemantEq, ACE/SAE, BEq+, BPF | whole-statement equivalence (see `docs/v0.9_cmcd.md` §1) | no certified model for an assumption change, no minimality |
| **leanscreen** (open source, Aug 2026) | informal↔Lean faithfulness *screen* (lints, vacuity/triviality checks, LLM judge), calibrated on 886 human verdicts | its authors state it may only *reject* and that a pass is not certification; no kernel-checked countermodels |
| **faithbench-neg** (v0 scaffold) | per-failure-class adversarial-negatives benchmark | a candidate *external* benchmark, not a checker |
| "claimcheck" | the ClaimCheck found is a web fact-checking system (Putta et al. 2025), not a Lean tool | not a competitor |

**Assessment.** We found no published or released system that certifies:
- that an assumption is *necessary*, *unneeded* or *substitutable* for a Lean statement, with kernel-checked models; or
- that a hidden assumption restricts a theorem, via a model read from the proof term.

This is a search of what we found, **not proof of novelty**.

## 2. Mathematics (all Lean-checked; fresh replay exit 0, LOCAL)

`lean/ProofScope/Composition.lean`: 15 theorems. 14 use no axioms; `substitutable_example` uses `propext`.

**Established theorems**

- **Linking.**
  - `linked_assumption_delta`: given kernel-checked `R ↔ RefS C P` and `L ↔ FormS C A P`, a certified
    model `m` with `C m ∧ ¬A m` yields `R → L`, `R → P m`, and the failure of uniform entailment back.
  - `same_text_different_structure`: one notation on one carrier with two meanings, so linking must
    compare elaborated terms.
- **Composition (polarity).**
  - `mono_lift` / `anti_lift`: monotone contexts preserve the direction of an entailment; antitone contexts reverse it.
  - `mono_comp` / `anti_anti` / `mono_anti`: the sign rule.
  - `mono_forall` / `mono_exists`.
- **Strictness through a context.** For a monotone context `k`, *every* strict weakening survives `k`
  **iff** `k True ∧ ¬ k False` (`strict_lift_iff`, no axioms).
- **Counterexamples to stronger composition claims.**
  - `degenerate_context`: a constant context erases strictness.
  - `exists_binder_absorbs`: a pointwise strict weakening becomes an equivalence under `∃`.
  - `empty_binder_absorbs`: a binder over an empty type erases every difference.
  - v0.9 `cancellation`: mixed directions cancel.

  *Consequence:* a local strict edit implies a global strict verdict only through a **global**
  separating model; v0.9's `monotone_strict` provides one when all edits point one way.
- **Minimality.**
  - `inclusion_minimal`: a sufficient selection where every member has a removal witness (a model of
    the others and the conditions where the conclusion fails) has no sufficient proper subset.
  - `redundant_drop`: an assumption implied by the others can be dropped.
  - `substitutable_example`: two copies of one assumption are each redundant but jointly necessary, and
    the inclusion-minimal selections are not unique.

  These certify **inclusion-minimality**, not minimum cardinality.

**Not established (open).**
- A complete linker for all Mathlib elaboration (coercions, universe polymorphism, `outParam` instances).
- A composition theorem for *dependent* binders whose types change between the two statements.
- Minimum-cardinality assumption sets.

## 3. Breakthrough A: dependent-structure linking

**Root cause of Mathlib m04/m05 (reproduced in core Lean with `[Mul α]`).** Shared instance binders were
printed with their **hygienic internal names** (`inst._@…_hyg.8`), so the canonical telescope could not
be re-parsed. The link certificate failed and the engine correctly abstained.

**v1.1 fix.**
- Binders get fresh accessible names.
- Instance binders are re-declared as instance binders (`[i1 : Mul α]`).
- Instance witnesses are `inferInstance` or one-field structures built from carrier operations, so two
  different structures on one carrier are both explored.
- Printing uses `pp.analyze` so ascriptions such as `(default : α)` survive (v1.1.1).

**Soundness argument.** Every certificate is elaborated in the canonical context, and a kernel-checked
`R ↔ canonical` ties that context to the original. A mis-resolved instance therefore makes the link
fail; it can never produce a false certificate.

**Core reproduction result.** `∀ α [Mul α] (a : α), …` against the version with a commutativity
hypothesis is now LEAN_WEAKER_BY_ASSUMPTION, with model `Bool, mul := fun a _ => a`.

**Mathlib.** m04 and m05 run again, unchanged, in **ProofScope v1.1 Mathlib Track**, together with five
new Mathlib cases not used in development (partial order vs totality, conjugation, a redundant
commutativity hypothesis for `CommMonoid`, two real-analysis minimality cases). **PENDING.**

## 4. Breakthrough C: assumption minimality (engine)

`adelta11.py`, minimality mode (`{"statement": …}`). For every assumption it certifies one of:
- **NECESSARY:** a removal witness;
- **REDUNDANT:** implied by the others;
- **UNNEEDED:** the conclusion follows from the others;
- **UNRESOLVED.**

Redundant pairs are checked for **joint necessity**. INCLUSION_MINIMAL is claimed only when sufficiency is
certified and every assumption is NECESSARY. Otherwise the verdict is
`INCLUSION_MINIMAL_IF_THEOREM_HOLDS` or `HAS_REDUNDANT_ASSUMPTIONS`.

**Examples (LOCAL, certified):**
- `∀ α op, assoc → comm → comm`: associativity is UNNEEDED; commutativity is NECESSARY (`Bool`, left projection).
- `∀ n, n ≠ 0 → 0 < n → 1 ≤ n`: both are REDUNDANT, and the pair is jointly necessary.
- `∀ n, 1 ≤ n → n ≤ 3 → …`: both bounds are NECESSARY (witnesses `n = 0`, `n = 4`). Sufficiency is not
  certified (nonlinear over a range), so the verdict is only conditional.

## 6. Breakthrough D: competitor benchmarking (protocol only)

No competitor was run in v1.1: SemantEq and ACE need Mathlib and could not be run locally.

`proofscope/competitors/v11_protocol.py` **pre-registers** the binary mapping and the scoring rules:
- ABSTAIN is never counted as correct or wrong;
- false equivalence and false difference are reported separately;
- there is a SemantEq JSONL exporter.

**Required before any comparison claim.** A benchmark written by someone other than the engine authors and
frozen first. A candidate is faithbench-neg once it has human-verified items. Without that, any result is
labelled "AI-authored, not human-adjudicated".
