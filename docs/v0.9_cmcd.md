## 2. Definitions (Lean: `ClaimDelta.lean`, `DriftSoundness.lean`)

- **Interpretation space.** `T` is the type of the operators shared by `R` and `L` that lie outside
  linear arithmetic and logic: `^`, `*` between variables, `gcd`, `List.length`, `List.reverse`, and
  so on. Abstraction is **per occurrence** (interpreted uses such as `2 * n` stay concrete).
- **Uniform entailment and countermodel.**
  - `SchemaEntails P Q := ∀ x : T, P x → Q x`.
  - `Separates P Q x := Q x ∧ ¬ P x`.
  - `StrictlyWeaker Q P := SchemaEntails P Q ∧ ∃ x, Separates P Q x`.
- **Edits and chain.** Edits are the maximal mismatching subterms of the two elaborated terms. The
  traversal enters binders with equal types, splits implications into hypothesis and conclusion, and
  enters an application only when exactly one explicit argument differs. The chain is
  `S₀ = R, …, Sₙ = L`, with every `Sₖ` abstracted over the same `T`.
- **Law policy.** Concrete rewriting with a fixed list of equational laws (commutativity, `gcd_comm`,
  `pow_two`, `length_append`, …). Every law tactic ends by *using the other statement* (`simpa … using h`,
  `exact h`, `(h x).symm`), so a law certificate is never a separate proof of the target.

## 3. Theorems (all checked by Lean; fresh kernel replay exit 0, LOCAL)

| Theorem | Statement | Axioms |
|---|---|---|
| `monotone_strict` | `A ⇒ B` (uniform), `C` strictly weaker than `B`, `C ⇒ D` ⊢ `D` strictly weaker than `A`, **and every countermodel of the step (B, C) is a countermodel of (A, D)** | none |
| `localize_weaker` / `localize_stronger` | the same, with the other edits schema-equivalent | none |
| `harmless_edit` | a schema-equivalent edit can be undone without changing any relation to the reference | none |
| `chain_entails_last` | a chain of uniform entailments composes | none |
| `equiv_symm`, `equiv_trans` | — | none |
| `cancellation` | **counterexample**: `x ≤ 1 → x ≤ 2` weakens, `x ≤ 2 → x ≤ 2 ∧ x ≠ 2` strengthens, and the end points are equivalent. Per-edit verdicts in mixed directions do **not** compose. | standard (`omega`) |
| v0.8 `ClaimDelta.lean` | soundness of separation, asymmetry, refinement, and the policy counterexamples | none |

**Candidate paper theorem (Localization).** Let `R` and `L` be elaborated statements with edit chain
`S₀ … Sₙ` over a common abstraction. Suppose every edit is certified uniformly forward-entailing and
edit `k` carries a countermodel `x`. Then `L` is strictly weaker than `R` as a claim about the shared
operators, and `x` witnesses this globally. Under the policy, the explanation "edit `k` weakens the
claim, as `x` shows" is therefore a kernel-checked fact about the whole pair, not a heuristic. Without
the one-direction hypothesis no such statement holds (`cancellation`).

**Block 1 failure analysis.**
- **`n06` (wrong).** `gcd a b → gcd b a` was split into two argument edits, creating the meaningless

### Adversarial suite `cmcd_v09_adversarial` (6 cases, block 2, single run, LOCAL)

- **False equivalence certificates: 0 of 5 eligible.**
- **Label match 4/6.** Both mismatches are **errors in the author's labels**, not engine errors:
  - `a1`: `n < 2^n` does imply `1 ≤ 2^n` for every interpretation of `^` (at `n = 0`, `0 < f 0`).
    The Lean-checked verdict CLAIM_LEAN_WEAKER is right.
  - `a6`: `2^n < n` is unsatisfiable at `n = 0` under every interpretation, so the true relation is
    LEAN_STRONGER. The engine said INCONCLUSIVE, not a wrong verdict.

  The labels are kept as written. This is direct evidence that same-author labels are unreliable, and
  it is why the blind suite must be written by someone else (`benchmark/cmcd_blind/README.md`).

## 6. Limits

- **Core Lean only**, which is the decisive gap for real research statements.
- **Policy-relative.** Verdicts depend on which operators are interpreted, and the law list is fixed.
- **Search-limited.** Witness pools and tactic portfolios are finite: an INCONCLUSIVE verdict means
  "not found", not "equivalent".
- **Order-dependent.** Edits are applied in traversal order. Localization is only claimed when every
  edit points in one direction.
- **Same author, small suites.** All results are on author-written suites (21 + 6 cases).
