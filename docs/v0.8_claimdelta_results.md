The full 208-case run is **PENDING** (workflow *ProofScope ClaimDelta Certified*). A first local attempt was interrupted before writing any results; it was restarted with the same frozen engine and a resumable driver, and no result was seen before the restart.

These cases have **no ClaimDelta ground truth**. The oracle labels from v0.6 are *pointwise* labels about hypotheses and conclusions; ClaimDelta judges the *closed claims about shared operators*. The table therefore shows agreement and coverage, not accuracy. Six of these cases (o005, o009, o042, o060, o129, o150) were inspected by hand during the v0.6 SemantEq analysis, before ClaimDelta existed.
