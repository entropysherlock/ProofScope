## 2. Mission 1: the two v0.5 held-out misses

Both labels were correct; both misses were proof-search limitations, never wrong answers.

| Case | Cause (reproduced in Lean) | Generic fix |
|---|---|---|
| `h_mod_bound_weaker_ok` (COVERS, truth EQUIVALENT) | The reverse direction `0 < m → n % m ≤ m → n % m < m` needs `Nat.mod_lt`; `omega` handles `%` only by literals, and `simp_all` and `grind` (even with lemma hints) do not find it. | `ps_arith` (`lean/ProofScope/Tactics.lean`): walks the elaborated goal and context, adds library facts for every ℕ `a % b` and `a / b` (`Nat.mod_lt` only after `0 < b` is proved by `omega`), then `omega`. | `h_quant_exists_weak` (INCONCLUSIVE, truth CONCLUSION_GAP) | `¬ ∀ k, k < 1` has no `Decidable` instance; `decide` cannot apply. | Witness search now splits conjunctions (`and_intros`) and closes each part with decision procedures, concrete instantiation (`h c`) or diagonal instantiation of a refuted ∃∀ (`hy y`, `hy (y+1)`). Every closer must finish its goal (`(tac; done)`): a first attempt failed because `simp` rewrote the goal without closing it. |

## 3. Soundness and observability theorems (`lean/ProofScope/Soundness.lean`)

Generic over `α` and `HL CL HR CR : α → Prop`, formal theorem `TL := ∀ x, HL x → CL x`, reference
`TR := ∀ x, HR x → CR x`. All nine theorems are kernel-checked, depend on **no axioms**, and pass `leanchecker --fresh`.

| Theorem | Statement | Use |
|---|---|---|
| `transfer` | hyp cover ∧ concl cover → (TL → TR) | COVERS |
| `equivalent` | covers both ways → (TL ↔ TR) | EQUIVALENT |
| `app_gap_blocks_cover` | (∃x, HR ∧ ¬HL) → ¬(∀x, HR → HL) | APPLICABILITY_GAP |
| `vacuous_says_nothing` | (¬∃x, HL) → ∀ C, ∀x, HL → C | VACUOUS |
| `concl_gap_refutes_reference` | (∃x, HR ∧ HL ∧ CL ∧ ¬CR) → ¬TR | CONCLUSION_GAP |
| `strict_concl_refutes_formal` | (∃x, HL ∧ HR ∧ CR ∧ ¬CL) → ¬TL | strictness |
| `observability` | TL ∧ TR → no conclusion-level witness in either direction | interpretation |
| `cover_vs_gap`, `vacuous_vs_inhabited` | the engine's INCONSISTENT pairs really are contradictory | soundness check |

**Consequence for auditing papers.** When the Lean theorem is proved and the paper's theorem is true, a *pointwise*
conclusion difference can never be certified (`observability`). Certifiable differences between two true statements are
therefore applicability gaps, vacuity and hypothesis strictness. Conversely, if ProofScope certifies a CONCLUSION_GAP
against a proved Lean theorem, the certificate refutes the **reference** (`concl_gap_refutes_reference`): the
transcription of the paper is wrong, or the paper's claim is false as written. This explains why the oracle benchmark
below contains no conclusion gaps: its references are true by construction.

**Completeness fragment (stated, not proved in Lean).** For natural-number binders with a finite box, every
existential obligation (gap, strictness, inhabitation) whose body is decidable is decided inside the box by
`decide +kernel`, so a witness that exists in the box is always found. Universal obligations have no such guarantee.

## 4. Mission 5: blind oracle benchmark

`proofscope/benchmark/gen_oracle.py`: 24 seed references in 7 areas (order, multiplication, division, modular
arithmetic, divisibility, powers, bounded quantifiers) × 11 mutation families → **175 cases**. Labels come from a
Python oracle that re-implements Lean's ℕ semantics (truncated subtraction, `n / 0 = 0`, `n % 0 = n`, `0 ∣ a ↔ a = 0`,
bounded quantifiers) and evaluates exhaustively on `[0,24)²`; it never calls Lean or the engine's proof search.
Existential facts are certain; labels resting on universals (EQUIVALENT, COVERS, LEAN_STRONGER, VACUOUS) are
grid-verified, not proved. Generation is deterministic (identical hashes across runs; checked in CI). The engine
was frozen before generation and the set was run **once**.

| Measure | Result |
|---|---|
| Exact labels | **154/175** (95% CI 0.82–0.92) |
| Wrong (non-INCONCLUSIVE) labels | **0** |
| Inconclusive rate | 0.12 (21 cases: powers, products and bounded-quantifier conclusions, where universal facts need nonlinear reasoning beyond `omega`) |
| Detection of fidelity failures | precision **1.0**, recall **1.0** (95% CI 0.94–1.0), false-positive rate **0**, coverage 0.88 |
| Certificates / contradictions / oracle disagreements | 943 / **0** / **0** |
| Runtime per case | median 6.8 s, p90 12.0 s (2 cores) |
| Naive syntactic baseline | precision 0.34, false-positive rate 1.0 |

Per family: extra hypothesis 24/24, incorrect constant in hypothesis 18/18, missing hypothesis 23/23, vacuity 24/24,
harmless rewrite 13/13; weakened conclusion 18/24, reversed inequality 10/16, strict vs weak 13/16, constant in
conclusion 8/11, quantifier bound 2/4, quantifier swap 1/2 (all shortfalls INCONCLUSIVE).

Limits: one author chose the seeds and mutation operators; the oracle model of Lean semantics was written by the same
author (a disagreement check against every certificate found none). Arithmetic domains only; no Mathlib structures.

## 5. Mission 2: research-statement dossiers (**GitHub-only, not yet run**)

The **ProofScope Research Audit** workflow builds a Lake project that pins Mathlib to the corpus's exact revision
(`d13f23b723b8a846827a245b89c10fc7d3f11612`), copies the comparator challenge statements unchanged, and extracts
dossiers for up to 150 statements selected round-robin across the corpus's subject areas. Verified locally: 416 of
418 challenges import only Mathlib (all 108 imported Mathlib modules exist at the pinned revision; 2 import the
corpus's own modules and are excluded); the 150-statement selection spans **20 catalogued areas** plus uncatalogued
statements. Comparator challenges are statements whose proofs are `sorry` by design, so their trust status is
STATEMENT_ONLY. Each dossier is linked to its scope document and papers; semantic review is NOT_REVIEWED.

Mathlib cannot be downloaded in the development sandbox, so the build and extraction have **not** been executed. The
isolated step was simulated on a local Lake project (network blocked, empty environment, one deliberately broken
module recorded as failed while the others built, replay limit honoured). The first GitHub run is the real test.

## 6. Mission 4: real research certificate (honest failed attempt)

No research-level semantic difference was certified in v0.6. Reasons, in order: (1) Mathlib-based certificates cannot
be compiled in the sandbox; (2) the ten AI-preliminary reviews and the two v0.4 paper-level reviews found no
discrepancy; (3) the observability theorem shows that, against a proved Lean theorem and a true paper theorem, only
applicability gaps, vacuity or hypothesis strictness are certifiable; v0.2 already established non-vacuity for five
real statements and none of the reviewed statements has a hypothesis stronger than its paper. The next concrete
target is an applicability-gap search on real statements once the Research Audit dossiers exist: compare each
challenge's hypotheses with the paper theorem's hypotheses and attempt `∃ x, H_paper x ∧ ¬ H_lean x` in Mathlib.

## 7. Security

Research Audit: the corpus's Lake configuration is never executed; network is used only for the pinned corpus
checkout and Mathlib (pinned revision, official cache); compiling and elaborating corpus files and extracting dossiers
run under `unshare --net` with `env -i` as the non-root runner user (the workflow aborts if the network is reachable).
Not isolated: the runner's filesystem, so a malicious corpus file could alter workspace files including evidence.
