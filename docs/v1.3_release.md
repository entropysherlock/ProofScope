## What failed before this release and why

* **Validation workflow red on every run after `d85cade`.** Not a mathematical failure: the new
  `refFalse` tactic list contained `decide at hbad`, which is not Lean syntax. The parse error
  rejected the whole obligation, so the false reference in cd009 was never refuted.
* **Silent label regression.** The `refValid` portfolio verified 1 of 21 references in the v0.8
  suite, so `cd_h03` and `cd_h04` dropped from `EQUIVALENT_BY_LAWS` to `CLAIM_INCOMPARABLE`. No
  test caught it. Fixed by adding core-library facts to the portfolio.
* **Guard missing in the fallback.** `scopeelim.fallback` still applied the law rule without
  `reference_status == VERIFIED`. Fixed, with a unit test.
* **Segmentation fault in the benchmark.** Z3 called from several threads. Infrastructure, not
  engine; the runner calls Z3 serially.

## Verdict taxonomy changes (migration)

* New verdict `REFERENCE_REFUTED` and new field `reference_status` ∈ {VERIFIED, REFUTED,
  UNVERIFIED, INCONSISTENT} on ClaimDelta rows.
* `EQUIVALENT_BY_LAWS` now additionally requires `reference_status == VERIFIED`. A case that
  previously had this label and whose reference the portfolio cannot prove becomes `CLAIM_*` with
  `law_status = IMPLICATION_PROVED_REFERENCE_UNVERIFIED`.
* `verdict_source` ∈ {scopeelim, scopeelim+claimdelta} appears when the fallback decided.

## What a decisive verdict rests on

Every decisive verdict is a set of declarations accepted by `proofscope.certify`; the statements are
the abstracted obligations, linked to the original statements by `Iff.rfl`. Python search results
are not trusted. **Not established:** that the Python grounding of a bounded Horn schema equals the
rule list for which `HornFin.entails_iff` is proved. Completeness of the bounded fragment is
therefore supported by the theorem plus agreement with exhaustive enumeration on 120 directions,
not by a formal correspondence proof.

## Known limits

Author-generated evaluation only; no blind or external benchmark. The Mathlib tracks of v1.0–v1.2
are still pending a GitHub run. `REFERENCE_REFUTED` detection is a small witness portfolio.
Separations produced through the ClaimDelta adapter are existence proofs that use choice.
